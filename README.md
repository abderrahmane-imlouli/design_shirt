#  Design Your Shirt

A modern interactive web application that allows users to create and customize their own T-shirt designs directly in the browser.

Users can choose a T-shirt size and color, add custom text, upload images, resize and rotate design elements, position them freely, and download the final design as a PNG image.

##  Features

*  Choose T-shirt sizes: **XS, S, M, L, XL, XXL**
*  Choose from multiple T-shirt colors
*  Add custom text
*  Change text colors
*  Upload custom images
*  Move text and images freely
*  Resize design elements
*  Rotate text and images
*  Delete selected elements
*  Real-time design preview
*  Download the finished design as a PNG
*  Responsive interface for desktop and mobile
*  Fully client-side — no backend required

##  Live Demo

##  Technologies

* **HTML5** — Application structure
* **CSS3** — Layout, styling and responsive design
* **JavaScript** — Interactive design editor and DOM manipulation
* **HTML Canvas** — T-shirt rendering and image export

##  How It Works

The application provides a simple design workspace where users can:

1. Select their preferred T-shirt size.
2. Choose a T-shirt color.
3. Add custom text and choose its color.
4. Upload an image from their device.
5. Drag elements to position them on the shirt.
6. Resize or rotate the selected element.
7. Remove unwanted elements.
8. Download the final design as a PNG image.

All design interactions happen directly in the browser.

##  Running Locally

Clone the repository:

```bash
git clone https://github.com/abderrahmane-imlouli/desin_shirt.git
```

Open the project folder:

```bash
cd desin_shirt
```

Then open `index.html` in your browser.

No backend or database is required.

##  Deployment

The project is deployed using **Netlify**.

Because the application is entirely client-side, it can be deployed directly from the GitHub repository without a server or build process.
