
# Design Shirt Web Application

Design Shirt is a web application that allows users to create custom T-shirt designs by uploading images, adding text, and previewing their design before printing.

This project was developed to practice interactive web development and user interface design.

## Features

- Upload images to put on T-shirts
- Add and position custom text
- Real-time preview of the design
- Basic responsive layout for desktop and tablet
- User-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose of the Project

This project helped me:

- Learn how to handle user input for images and text
- Practice DOM manipulation using JavaScript
- Understand interactive frontend design
- Prepare for more advanced projects with backend integration
